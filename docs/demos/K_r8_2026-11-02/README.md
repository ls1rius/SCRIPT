# K-r8 真实数据链路 Demo

以下3例均来自正式K-r8已完成题目。没有调用模型、重答或修改实验。K以F为基础；这里不是I→L。

“实体化信息”指逐采样事实和上游局部实体／状态／关系档案；并非统一物理身份库。候选池还包括保留原文、时序假设和已有视觉观察。

每例按：原问题与选项 → 完整结构化档案 → 全部候选与实际规划输入 → 原始决策与保留证据 → 实际最终输入。

聊天中的展示可节选；本目录的JSON、Description和聊天模板文本均完整保存。`head`是system消息，`prompts[0]`是user消息；`query_id`仅为调用元数据。原提示中的prediction/explanation/confidence指令保留原样，r8在解码层约束最终输出仅prediction:A–E。

| 案例 | 候选 | 保留 | 跳过 | 模型分组 | 最终输入token |
|---|---:|---:|---:|---:|---:|
| [书作为绘画表面：有真实分组](01_book_merge/demo.md) | 97 | 19 | 78 | 1 | 1534 |

每例的`demo.md`按顺序展示原问题、选项、实体档案、全部保留正文、完整分区和无删减最终输入。`03_candidate_pool.json`包含筛选前所有数据；`05_raw_planner_output.json`是原始规划输出而非事后解释。

反例也按原样保存。模型对“跳过”的选择并不自动表示证据无用；分组及文字审计不构成语义充分性证明。
