# 证据保留与筛选：O/O+ 的坑点及 Q/Q+ 的执行要求

记录日期：2026-11-05。用于后续方案设计、提示编写、实现和实验复核。

**Q4/Q4+训练版（2026-11-06更新）：** 依用户最新要求，全部200题连续盲训固定6个epoch，LoRA与优化器各初始化一次，无内部验证、选轮或全量重训。已完成真实6轮，直接使用第6轮权重，正在原300题开发验证；适配器仅在贡献筛选q3_filter启用。现行目录为 `workdirs/Q4-trained-fixed6-200train-300val-20261106-r1/`，不得恢复旧180/20方案。


**当前默认研究/评测方案（2026-11-06用户确认）：Q v4自适应，Q4+为首选和主要报告结果，Q4保留同证据对照。** 未训练基线 `workdirs/Q4-adaptive-500-20261105-r1/` 已完成500题，Q4+/Q4均316/500。后续优先比较Q4+的准确率及完整成本；最终读者省token/更快不等于共享筛选、复核、补取流程同比提速。v3补取完整版与L保留历史对照。固定6轮LoRA版尚在300题开发验证，暂不自动替代基线。普通 `script_qa.py query` 仍为L入口。

默认完整流程保留完整原句贡献筛选、only-keep、筛选前后比较复核、针对性重判、按缺口补取、充分性早停及同证据双读者，最多补读4个N caption档案场景。关闭早停的 fixed_depth_control 仅保留为历史消融结果，不再并列默认方案，也不默认每轮重复运行。它同样启用完整补取，不是固定来源版。未来版本独立导航、筛选和回答，不复制v4旧答案或最终补取集合；完整补取不代表全视频重识别或无限补读。两组已全部完成，本次定位更新不启动模型或改动冻结运行产物。

**筛选的目标是判断“这条观察是否可能贡献证据”，不能要求“这句话能否独立回答整个问题”。单条证据不充分，不等于它不相关。**

本文把已确认的问题、应遵守的要求、Q/Q+ 当前实现及尚未解决的限制分开记录。要求写进提示或通过格式检查，不代表模型已经稳定做到；准确率改善需要实际配对评测。

**最新策略（2026-11-05 用户明确修订）：只有 `keep` 进入 Q/Q+ 最终回答。`uncertain` 仅保存为审计记录，不进入读者输入。** Q v1 曾采用“不确定也保留到回答”的策略；该策略已被撤回，不能沿用旧说明指导后续运行。保留档案与作为回答证据是两个不同动作。

## 1. 应要求保留哪些信息

保留可能支持、限制、比较或反驳某种解释的观察，以及理解这些观察必需的组成部分。

| 应保留的信息 | 要求与原因 |
| --- | --- |
| 局部动作与过程步骤 | 拿起、放下、移动、装入、调整等可以共同构成活动。不能因为单次动作没有说明整个目的而删除。 |
| 主体、对象和人物关系 | 保留谁对什么做了什么，以及给予者、接收者和协作关系。不能只留下动词，或把另一个人的动作绑到当前主体。 |
| 改变含义的角色与修饰 | 保留必要的工具、身体部位、位置、目的地、来源地、方向、方式等。字段值出现在原句中，也不代表角色分类正确。 |
| 否定、条件和不确定性 | “没有打开”“可能移动”“如果……则……”不能被压缩成肯定动作。这些内容也可能是反证。 |
| 顺序、阶段和时间来源 | 保留明确的前后关系、观察时间区间和来源标识。不能为了简短而删除前后阶段的区别。 |
| 部分证据与不同解释 | 一条观察可能同时兼容多个解释，仍应保留；不能先偏向某个答案，再删掉其他解释的证据。 |
| 独立身份或上下文线索 | 身份、场所、进入/离开等可能帮助理解人物互动和阶段变化；不能一律当成“没有动作，因此无用”。 |

“保留完整事实”指保持一次观察中的语义绑定。只留主体、动词，删掉决定其含义的对象或角色，可能制造新的含义。

Q 当前以**完整原句观察**为单位：保留就保留整条，不逐字段删改。原句同时含相关和次要信息时，Q 不再生成式拆分它；这是明确的召回与长度取舍，不是字段级最小证据算法。

### 不能作为删除理由的说法

- “只出现一次，不能证明反复发生。”反复模式需要先收集各次观察。
- “这句话没有同时描述两个阶段。”阶段比较需要不同观察共同支持。
- “没有说明整体目的/动机。”具体动作、对象和过程可以贡献目的判断所需的证据。
- “这条信息支持不止一种解释。”有歧义不等于没有信息。
- “主体或对象单独不能回答问题。”它们可能是理解完整动作必需的部分。
- “上下文不足以判断重要性。”这可进入 `uncertain` 档案，但不能直接断言观察无关；当前策略也不把它交给最终读者。

不能把“可能贡献”无限扩展成任何想象出来的联系。判断应依照原问题、当前实际观察及允许的同题上下文；明确无关的颜色、背景属性或事件仍可删除。不设固定保留数量，也不把保留越多直接等同于质量越好。

## 2. 筛选判定合同

| 决策 | 判定标准 | 后续动作 |
| --- | --- | --- |
| `keep` | 当前观察可为问题所涉及的活动、人物、对象、阶段、比较、过程或反证贡献证据；不要求充分证明结论。 | 保留完整观察。 |
| `uncertain` | 无法确认当前观察与问题有关；单句不能独立证明全局结论，并不自动使一条明确相关的局部观察变成 uncertain。 | 仅归档完整观察和判定，不进入 Q/Q+ 最终回答。 |
| `drop` | 有充分理由判定它与问题及相关过程无关，而不是仅因单句不充分。 | 删除该观察；保留原文和原始决策供审计。 |

例如，问“清洁中反复发生什么”，`J wipes a shelf` 是应收集的一次观察；`An unused clock is purple` 可以删除。问“是否打开容器”，`J did not open the container` 应保留为反证。

### 编写提示时可采用的核心要求

> 你负责收集观察，不负责回答整道题。判断当前观察是否可能为问题贡献局部证据或反证，不要求它独立说明整体目的、全部阶段、频率或最终结论。明确相关的局部观察输出 keep；无法确认相关性时输出 uncertain，仅归档、不交给最终读者；明确无关才输出 drop。不要猜测具体答案，再据此缩窄筛选范围。保留 keep 观察中的人物、动作、对象、关系、否定、事实本身的不确定性及必要修饰。问题与选项不能提供观察中不存在的事实。

“来源说某件事可能发生”和“筛选器不确定它是否相关”必须区分：前者若明确相关，应 `keep` 并原样保留“可能”；后者才是仅归档的 `uncertain`。不能把需要多条证据共同支持结论，等同于这条局部观察不相关。

这是中文概念模板。Q 当前实际英文提示、严格输出 schema 和完整行为，以 [q_evidence.py](../script_core/q_evidence.py) 及运行目录冻结副本为准。Q 模型仅输出决策，不生成事实解释或任务规划，避免新生成的叙述反过来充当证据。

## 3. 必须记住的其他坑点

### 问题规划可能先猜答案，再驱动误删

即使没有提供选项，模型也可能从泛化问题自行猜出某个具体任务。“设备做了哪些调整”不能被改写成“只找高度调整”；“整体目的”也不能被扩写成某个未经观察的用途。

如果使用问题分解，只能整理问题明确提出的比较、人物、时间段或过程要求；不能加入未经来源支持的动作、对象、地点或目的。Q 当前直接去掉 `o_filter_plan`，不把生成的任务假设交给筛选器。

### 单句独立判断不足以处理全局问题

“整体主题”“反复模式”“前后阶段”“人物配合”需要跨观察汇总。Q 允许读取同一道题内的当前句及来源序列中前后各一条观察，但只决定当前句是否保留。

- 相邻指来源序列中的相邻项，不自动表示连续发生或同一事件。
- 邻句只能帮助判断当前句的相关性，不能把邻句动作补写进当前句。
- 不同问题不得共享模型提示、邻接上下文或证据绑定。
- 这个有限窗口尚不能保证完成全局覆盖判断。

### 原文出现过，不等于角色和语义正确

介词 `in/on` 被抽成动词，把“杯子里的水”写成动作来源地，或把身体部位错标成工具，均可能在格式合法时发生。对这些错误做忠实重组，仍会输出错误结构。

“字段字符串来自原文”“JSON 合法”“属于有限枚举”只能证明各自的技术合同，不能证明动作、角色、关系、否定和主体绑定正确。Q 当前绕过生成式角色抽取，直接保留字面原句；这降低了一类重写风险，但不证明原始 caption 本身是真实、完整的视频事实。

### 来源缺失和后续误删必须分别定位

需要分别检查：原始来源是否已经缺失 → 抽取是否损失或改变信息 → 筛选是否误删 → 呈现与最终读者是否误判。

关键观察未进入来源时，后续筛选或重组无法忠实恢复它。不能用猜测补齐，也不能把所有相对 L 的失分都归咎于筛选。Q/Q+ 本轮固定 O 的原 N 已选来源，尚未增加上游补取；来源覆盖缺口保持公开记录。

### 表达、删减和推断是不同操作

旧 O+ 曾自由补写目的和其他事实；来源约束 v15 已改为从已选字段构成的有限表达中选择，仍允许整组删除。不能用旧自由重组的缺陷直接解释当前 v15 的全部错误。

O+ 与 O 的差异包含呈现变化和进一步删组，不能笼统称为“格式差异”。即使不删组，最终读者也可能因为呈现变化选出不同答案。Q+ 当前使用固定紧凑呈现：与 Q 的观察字节、顺序和来源时间完全相同，不再模型重组或另删组。

## 5. 对实验结果与成本的解释要求

- O/O+ 完整 300 题分别为 173/176 正确，N 为 171，L 为 189。O 相对 N 修正 18 题、退步 16 题；O+ 相对 O 修正 10 题、退步 7 题。必须同时报告修正和退步，不能只展示成功案例。
- O+ 在 285 道没有额外删组的题中修正 7 题、退步 7 题；另 15 题出现删组，贡献净增 3 题。这是观察分组，不是“删组导致提升”的因果证明。
- O+ 本次重组平均约 16 秒/题，最终回答仅比 O 少约 0.13 秒/题。回答输入缩短不能直接证明整条处理链路省时。
- 比较准确率应匹配实际完成的同一批题目与选项顺序；并行完成顺序不同，不能只取默认方案前 N 题凑相同数量。
- 导航、抽取、筛选、规划、呈现、复核和最终回答的成本边界要明确；共享工作计一次，继承成功依赖不能漏计，失败/中断成本不能抹去。共卡耗时不当作受控速度倍数。
- 格式/隔离/预算检查、合成真实模型检查和正式 QA 准确率是不同证据。检查通过不证明误删已解决；答对也不证明证据选择和角色语义都正确。
- 当前 300 题已经参与前轮分析，Q/Q+ 是分析后的架构评估，不能称为未见 holdout。修复应采用通用规则，保留旧版本与失败档案，不针对已知答案调标签。

## 6. Q/Q+ v2 落实与待验证项（历史版本）

| 事项 | 当前落实 | 限制/待验证 |
| --- | --- | --- |
| 防止规划猜答案 | 不调用问题规划器，筛选直接读取原问题。 | 不保证模型内部不会偏向某种解释，仍需审计实际删除结果。 |
| 收集局部证据并控制干扰 | `keep/uncertain/drop`，只有 keep 进入回答，uncertain 仅归档；提供至多两个同题邻居。 | 不再把候选池等同于最终证据；需同时评估召回损失与无关信息负担，提示不保证全部判断正确。 |
| 完整事实与来源 | 保留完整原句、可逆标签移除 offset、来源标识和时间；不生成角色结构。 | 不修复 caption 错误，不补缺失来源，不进行全局事件合并。 |
| Q/Q+ 对齐 | 同一保留集合生成结构化版和固定紧凑版，再分别新回答。 | 呈现一致不保证最终答案一致；准确率与成本要实际配对比较。 |
| 容量与隔离 | 按实际 tokenizer 检查容量，不截断；批内独立 tensor/解码状态，同题上下文，题间独立。 | 配置并发数不等于实际上卡数；以 worker 状态与资源准入为准。 |

## 7. Q v1 的后续坑点及 keep-only 修订

以下是 `00:29:37` 的同批 106 题诊断快照，不是最终 300 题成绩：L/O/O+/Q/Q+ 分别正确 59/58/56/56/55 题。完整配对和归因边界见 [Q v1 退步分析](history/Q_Qplus_Regression_Analysis_2026-11-05.json)。

1. **归档候选池不能直接等同于最终回答证据。** Q v1 将 7,235 条观察中的 6,891 条交给读者，其中 3,441 条为 `uncertain`，占读者观察的约一半；最终输入又没有传递“相关性待定”的区别。防误删的取舍变成了大量待定观察与明确相关观察共同平铺。用户据此要求取消 uncertain 进入回答，v2 只使用 keep。记录和保留候选并不要求模型作答时读取它们。
2. **新增退步不一定是删掉了旧证据。** 这批 Q 相对 O 的 3 道新增退步题，全部仍覆盖 O 曾保留的来源句。环境改造题从 68 句变成 108 句全留；人物互动题从 18 句变成 32 句。可以确认输入负担和组成改变；“干扰导致该题错误”仍需受控消融，不能只凭相关性作完整因果断言。
3. **问题中的预设不能变成观察事实。** 询问“人物如何交流/配合”不证明交流或配合确实发生。不同人物各自切食物，不足以直接认定他们协作；同场、相近时间和相似动作也不自动证明交互关系。
4. **跨时段问题要核查实际来源覆盖。** 阻力带题询问 `[0,180)` 的前后半段，原 N/O 来源只覆盖 `[0,15)`，N 却以 sufficient 停止。Q 保留这 14 条来源并不能补回后半段；O 偶然在相同不足来源上答对，也不证明已经可靠验证时间对比。这个检查应服从问题明确要求，不能推广成所有题强制读完整视频。
5. **固定压缩仍可能改变读者答案。** 木工题 Q 在相同 58 条证据上答对，Q+ 答错；社交题两版同样保留 146 条观察，却选择不同答案。证据 hash 相同只能证明没有额外删改，不能证明两种排版对读者等价。
