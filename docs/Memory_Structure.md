## 通用化表达约定

- 保留实体、动作／事件、实体关系、变化与结果、事件联系这些第一层概念。
- 属性保留 `PROPERTIES = ('color', 'material', 'shape', 'size', 'texture', 'pattern', 'appearance', 'other')`；每条属性记录所属实体、属性类别、属性值及来源和时间，属性值不预设枚举。
- 状态取消固定的 `DIMENSIONS` 分类，不再要求选择 `cleanliness`、`wetness`、`integrity` 等维度。最小表达为实体、开放的状态描述、观测时间（或有依据的有效时间）、来源引用；通用版状态主结构不要求 `dimension/value` 字段。
- 单次观测不证明整个时间段持续成立；同词状态也不必然等价，时间合并需保留依据、否定与不确定性。
- 动作角色、关系子类等同样不应成为针对某个数据集穷举的封闭词表；已有角色可作常用表达示例。
- G 的独立实现采用上述状态描述结构；原 E/F 等冻结实验的枚举 schema 和结果保留原版本。主查询入口仍使用 D，尚未切换为 G。
