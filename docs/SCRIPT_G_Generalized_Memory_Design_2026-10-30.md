## 已确认的结构

第一层保留实体、动作／事件、实体关系、变化与结果、事件联系。概念图见 [记忆结构图](Memory_Structure.md)。

| 部分 | G 的设计 |
| --- | --- |
| 实体 | 保留 ID、名称、别名和对应记录的关联；未知身份不强行合并 |
| 属性 | 保留 `color`、`material`、`shape`、`size`、`texture`、`pattern`、`appearance`、`other` 八类，属性值开放 |
| 状态 | 取消固定 `DIMENSIONS`；记录实体、开放状态描述、时间和来源，不要求 `dimension/value` |
| 动作／事件 | 保留动作内容、参与对象和现有常用角色；无依据的角色不补写，执行者未知时允许缺省 |
| 实体关系 | 保留空间、持有、部分与整体、连接、其他这些常用类别及关系描述 |
| 变化与结果 | 分别记录有依据的前后条件及明确结果，无额外固定子类 |
| 事件联系 | 保留先于、后于、同时、原因、目的；顺序不自动升级为因果或意图 |
| 证据 | 保留来源原文、观测时间、引用和信息依据；未可靠结构化的信息继续保留原文 |

## 实现与验证边界

G 的状态变更需要同步覆盖提示、输出 schema、接收校验、实体关联、时间段组织、最终呈现和审计，不能仅删除 `DIMENSIONS` 常量。状态描述的观测时间与有依据的持续时间分开；重复描述不自动证明中间时段持续成立。

延续 E 的局部身份处理不代表已经具备完整的全视频统一实体身份层。结构设计的通用性尚不等于跨数据集性能已验证；后续实现和评测应单独记录版本及结果。

## 首轮执行协议

- 复制 E r3 的冻结运行时、300 题、全部允许来源和原始回答输入；仅在副本添加 G 的操作及模块。原 QA 调度与适配器、权重、精度、生成配置及解析协议保持相同。
- 每个来源联合抽取七类；未知执行者不补写；开放状态描述仍需来自同一来源原文，有限的同句校验不等于完整语义证明。复杂、失败或不确定信息保留原文。
- 状态按实体和来源描述的精确匹配组织采样支持，不引入固定语义维度或自动同义合并；沿用 E 的 8 秒局部身份窗口和 2 秒采样间隙上限。连续性是有界文本推断，原采样点完整保留。
- 每题沿用 1500 秒抽取预算、45 秒回答预留；模型准备、功能检查、失败调用和各阶段成本分别记录。每题只生成一次 G 最终答案，不复用 E/F 的抽取或答案作为 G 预测。
- 主比较为 G 与 E 的同题配对；A/B/C/D/F 分别按共同完成题目报告，未执行题目不计错。角色缺省与状态结构变化属于本次组合变更，不据此单独归因。
- GPU 0 连续三次达到 32 GiB 空闲后加载独立常驻模型；允许共享 GPU，不停止现有任务，观测耗时不作为受控算法加速比。基础设施失败不自动重试，保留所有尝试。
