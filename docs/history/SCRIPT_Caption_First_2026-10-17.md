# 每秒描述优先的少看流程

2026 年 10 月 17 日，新加坡时间。针对[上一轮分析](SCRIPT_Guided_Performance_Analysis_2026-10-17.md)中“原始每秒描述完整传入，却未被有效综合”的问题，本次将少看流程改为先作描述判断，再按具体缺口补看。少看组真实复验已完成，结果为 **142/300（47.33%）**，低于上一轮 163/300（54.33%）；常规读取组已完成：171/300（57.0%），2 道失败保留计错。本次实现没有取得准确率改善，不能称为效果已验证的改进。

## 行为变化

原流程先根据窗口描述生成读取计划，再补看，最后回答；缺少独立保存的描述初判，而且观察目标被统一替换成泛化描述。新流程为：

1. 在适用少看的题上，直接读取原始 LaViLa 每秒描述及原时间，去掉窗口包装造成的重复。不同秒出现相同描述仍分别保留，不合并为一次动作。没有外部描述时使用已有窗口描述；超出查询合法范围的生成描述不冒充范围内信息。
2. 一次 `caption_review` 调用先回答，再列出最多一个会影响选项选择的可见缺口。初判保存具体描述引用；这是描述依据，不创建已核验视觉事实。
3. 描述足够时返回空检查，零读图直接复用初判，避免对同样输入再猜一次。需要补看时，给出具体中立问题、窗口及附近描述引用；观察和验收收到原检查问题，不再统一抹去具体区别。
4. 每次检查后使用完整描述、已核验局部事实及带时间的未知信息重新判断；下一次仍最多一个窗口，总计最多三次，已查及高度重叠窗口仍排除。
5. 补看后最终回答接收完整去重时间线和有效事实，移除重复的窗口描述与场景摘要，不输入先前选择作为答案提示。保存初判、历次描述判断、最终选择及是否改变，方便离线计算修对和改错。

描述时间线采用平铺文本；候选仍保持编号与全文对应，模型输入不再额外重复整组选项差异文本。描述初判与首次检查共用一次模型调用，替代原来的首次读取规划；每轮判断也替代原规划，不额外叠加同类调用。普通题的问题解析暂时保留，不能将本次变化说成已经解决全部解析开销。

## 配置和证据边界

当前默认 CLI 的 `configs/script.yaml` 使用修复后的常规读取：`reading_policy: coverage_first`、`caption_first: false`；`configs/script_coverage.yaml` 提供显式同策略配置。要启用本报告的描述优先少看流程，使用 `configs/script_guided.yaml`（`script_guided`、`caption_first: true`）。在少看配置下，`query.caption_first: false` 保留旧的逐次 `read_plan` 流程作为消融。严格计数、否定、最后一次等不适用少看的题沿用覆盖流程。已提交的两组复验继续使用冻结配置，不随工作区默认值改变。

描述初判、规划停止、零读图均不会把证据状态提升为充分；描述 ID 不能进入视觉事实引用字段。检查问题是待查线索，不能被当作已发生的动作。既有视觉核验的动作/状态语义漏洞尚不属于本次修复，仍需通过独立修复与验证处理。

新增实现位于 [caption_first.py](../../script_core/caption_first.py)，控制流程位于 [controller.py](../../script_core/controller.py)，约束和提示分别位于 [schemas.py](../../script_core/schemas.py)、[prompts.py](../../script_core/prompts.py)。

## 已完成验证

**212 项 CPU 检查通过**，日志保存到新实验的 `cpu_tests.log`。新增 8 项检查覆盖：描述直接回答无需读图/再次回答、具体问题传给观察、事实反馈及窗口排除、三次上限、规划失败后保留描述作答、原始秒级时间与文本保留、描述/视觉引用隔离、真实约束解码器及配对评分中的错误计入。部分性质由同一项检查同时覆盖。

对固定 300 个 M0 的原始描述做了逐条审计：**54,000/54,000 条原文和时间均被新时间线保留**，没有重新建库，没有使用答案。审计记录为 `caption_timeline_audit.json`。

CPU 检查验证流程边界和记账，不证明模型准确率提升。初判来自同时回答和安排检查的 `caption_review` 调用；它不是独立的 VideoTree 提示模板控制组。初判与终判的配对收益可观察，但仍混合了补看事实、后续判断与最终回答提示的影响，不能当作随机消融得到的纯视觉因果收益。

## 真实模型复验

### 少看最终结果与退步分析

新少看组 300/300 完成，正确 142，失败 1，平均在线 31.36 秒/题，预算违规为零。相对上一轮 163/300，112 题两轮都对，51 题旧对变错，30 题旧错修对，107 题都错；净少对 21 题，下降 7 个百分点。

问题并不是“最多三次还不够”，而是新少看分支没有真正补看：286 道题进入该分支，285 次成功描述初判原始输出全部为 `checks=[]`；另 1 题描述规划输出解析失败，仍通过最终描述问答完成。286 题实际视觉读取均为零。其余 14 题沿用覆盖流程，取得 7 个正确答案。285 次成功初判均有 26–28 个候选窗口和一次读取额度，说明不是没有窗口或程序把读取预算设成零。用真实输入对应的约束解析器构造非空检查也能合法结束，空检查并非该 JSON 字符语法强制要求；模型为何始终结束仍需独立的提示/解码回放确认。

此外，不能把全部退步归因于删除视觉：51 道退步题中，6 道上一轮也零读图，9 道上一轮最终没有有效视觉事实。两轮输入仍保留原始每秒描述，选项展示映射没有变化；最终问答提示、输入组织、引用任务和零读图时直接复用初判则同时变化。因此当前已观察到的是“描述问答退步，加上本应存在的补看路径完全未触发”，各变化的因果贡献尚未隔离。

285 次成功初判中，225 次引用全部落在前 30 秒，150 次解释与所选选项文字高度相似（小写 `SequenceMatcher` 比率大于 0.85 的启发式统计）。引用只检查 ID 合法性，没有检查描述是否支持对应选项。这使“引用几个描述 ID”并未成为有效的语义检查。

三个具体案例显示，已有描述也没有被有效使用：

- `8345d177` 刺绣题：原文 21 秒就写了绘制图案，56 秒出现铅笔；VideoTree 所选描述保留这两处并答对。新初判只引用最初 0–4 秒针线共同动作，却选择“先剪布”，没有触发核查；上一轮取得笔/绘图视觉事实后答对。
- `f1d2978d` 烘焙题：VideoTree 所选描述含 30 秒 flat bread、97 秒 tray of bread 并答对面包。新流程也拿到这些原始描述，却引用一般面团/托盘动作，选择披萨并立即停止。
- `0c17076e` 面团顺序题：原文 0 秒台面滚面团、5 秒面粉、12 秒入托盘已提供区分。上一轮虽无有效视觉事实仍答对，新流程引用开头 0–4 秒并选错顺序。

最值得验证的机制是联合“先回答、再判断需不需要看”产生自我确认，配合“已有描述足够即可停止”的提示，导致检查分支全部关闭。这是与日志一致的机制假设，而非已完成单因素消融的结论。此前工程验收只保证合法输出、预算与引用边界，没有验证真实模型会在这些缺口题上产生有效检查；不能用 CPU 测试通过说明该策略有效。

### 与 VideoTree 兼容的扩展定位

SCRIPT 可以设计成 VideoTree 的按需证据扩展，但当前实现尚未严格做到“关闭扩展即回到原 VideoTree”。本仓库的 VideoTree 在 [demo.py](../../demo.py) 中执行自适应宽度、相关性驱动深度扩展，再由 [main_qa.py](../../main_qa.py) 和 [prompts.py](../../prompts.py) 对筛选后的时间描述做 QA。新少看虽然复用了原始描述和模型，却没有沿用该筛选结果与原 QA 调用，而是对全部描述做了另一种联合问答与停止决策；这不能算保留了一个已验证的 VideoTree 基线。

| 环节 | 应复用的 VideoTree 能力 | SCRIPT 的扩展位置 |
| --- | --- | --- |
| 基础导航 | 原有帧特征缓存、树节点与每秒描述 | 时间邻接、节点到原始秒数的映射；避免重复构建同类索引 |
| 问题相关检索 | 自适应宽度与深度扩展，按时间保留相关描述 | 将缺少的选项区别反馈给检索与局部观察 |
| 初始问答 | 原 QA 模板、选项呈现和生成流程 | 原样保存基线答案及输入，扩展关闭时完整复现 |
| 细节核查 | 已选节点及其时间支持 | 按需读取原帧，建立带来源、时间和依赖的局部事实 |
| 最终更新 | 保留原描述上下文与基线答案 | 仅在新增事实解决关键区别时允许修正，并记录修对/改错及成本 |

VideoTree 的聚类节点可能包含多个不连续时刻，不能直接把一个簇当成连续场景区间来证明覆盖。SCRIPT 可将其原始索引集合映射为若干合法观察窗口，视觉事实图作为查询工作层附加，不需要先为整片建立实体和交互图。

建议的验证顺序是先复现原 VideoTree 调用路径，再增加 SCRIPT 检索/反馈层，最后增加视觉核验及依赖记录。每步分别报告相对原 VideoTree 的修对与改错；没有新增区分事实时保留基线答案，避免普通共同动作或无依据的第二次判断覆盖它。视觉核验自身仍可能错误，保留回退能力也不能保证准确率只升不降。

同题历史 VideoTree 为 195/300（65%）；新少看与它有 110 题都对、32 题仅新少看对、85 题仅 VideoTree 对、73 题都错。说明应该保留它有效的检索/QA 路径，再用扩展争取处理剩余问题，而不是把重新实现的描述 QA 当作等价基线。新的九组固定证据迁移实验已实现并提交；首轮因配置解析问题中断，修复后于 2026-10-18 重新提交，详见[迁移实验记录](SCRIPT_Migration_Experiments_2026-10-17.md)。常规组已完成：171/300（57.0%）。
