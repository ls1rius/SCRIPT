## 决策、合并与最终输入

规划器内部输出（r4）：

```json
{
  "R0": "keep",
  "R1": "skip",
  "R2": "uncertain",
  "R3": "group:R3",
  "R4": "group:R3"
}
```

每个候选 ID 是一个固定顺序的必填键，只能生成一次。值只能是 keep、skip、uncertain 或合法 group:Rn。共享同一组名的记录合并呈现；组名仅是标签，不隐式加入对应编号的证据。单成员组直接作为单条保留。程序转换为内部四列表分区后仍执行完整覆盖、唯一分配和非全跳过审计，原始输出与转换后的计划分别归档。`uncertain` 继续保留。跳过只影响本次回答，不删除来源档案或 F 数据库。

合并以保留事实为前提：完全相同正文／证据性质共用正文并列出各次采样；不同但互补的陈述可以组成一段，但逐条原陈述和时间继续保留。不自由生成归纳句，不做未经验证的同义句折叠，也不推出持续时间、物理身份或事件次数。

最终证据用句子模板呈现，不直出 `Action: actor=...`。规划器只能输出 ID 对应的决定和分组，不能通过自由改写引入新事实。程序保留完整候选到来源映射、跳过列表与分组审计。

K 构建最终输入时，移除原提示中整个旧时序／视觉辅助区域，将选中的各区域证据统一放入 Description，防止跳过的信息从其他区域再次进入回答。问题、完整选项、回答任务指令和格式要求保留。源性质、不确定性和离散采样限制通过自然语言提示保留。

这是受约束的来源组织与选择，程序检查不能证明语义正确、证据充分或模型理解可靠。
