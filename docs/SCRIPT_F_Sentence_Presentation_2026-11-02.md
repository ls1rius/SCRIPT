# F：用完整句子呈现结构化事实

2026-11-02，新加坡时间。用户要求默认按需版 F 将结构化事实组织成完整句子，不再向最终回答模型直出 `Action: actor=...; verb=...` 等字段串。

工作区呈现版本为 `F-fact-sentences-v1`，实现于 `script_core/qa_evidence_view.py` 的 `narrative_description`。普通 F 查询及今后新准备的 F 离线运行使用此呈现；既有冻结实验、数据库、逐题输入和结果没有改写。E、I 继续使用各自既有呈现。

例如，内部仍保存：

```json
{"actor":"C","verb":"picks","patient":"carton paper"}
```

本采样点的回答输入变为：

```text
Frame [137,138): C picks carton paper.
```

动作模板组合执行者、方式、动词、对象及已有角色；材料、工作表面、位置使用额外的完整句子表达，避免猜测原文的 in/on/under 等介词。属性、状态、关系、变化、结果和事件联系也有句子模板。实体标签、原始动词和字段值不自由改写，不补写缺省角色，不将时序联系升级为因果。结构分类继续保存在存档中。

如果原投影保留了原文（包括否定、不确定或不完整抽取），继续呈现原文，不重复展示它的衍生字段。每个采样点单独保留，不合并成连续动作，不进行相关性筛选。未知字段在没有原文时明确报错，避免静默丢失内容。

本次只改变 F 的 Description 呈现；问题、选项、上游时序记忆、视觉补充和回答协议保持既有流程。没有训练证据筛选器，也没有启动模型或重跑评测。

验证：使用统一 vts 解释器完成 63 项 CPU 检查；只读重呈现正式 F 的 300 题记忆，共 30,141 个采样点（其中 2,134 个以事实呈现），来源与采样点完整保留。该验证不代表准确率或运行耗时已有改善。
