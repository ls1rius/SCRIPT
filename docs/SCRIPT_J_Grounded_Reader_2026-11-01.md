## 范围与实现

核心为 `script_core/grounded_reader.py`，当前版本 `grounded-reader-J-v3-candidate-quotes`。独立入口为 `script/run_grounded_reader_experiment.py`。当前接入离线实验，尚未添加 `script_qa.py --memory J` 普通查询选项。

J 正式实验继承封存的 H→I 全部证据、字段规划、开放状态、八类属性、未知执行者规则及源盲抽取。J 不新增来源抽取、图像读取或检索，不用旧答案作提示。正式入口显式拒绝历史 F 来源的 I，不继承已删除诊断的成绩。

包含全部改进：

1. **重复信息压缩**：继承 I 的完全相同正文合并和相邻区间合并，再按来源盲规则归一空格、冠词、进行时和 cellphone 拼写。保留执行者、动作、对象、工具、方向、左右手、否定及所有原始来源。允许等价正文跨采样共享一行，但所有离散区间及原顺序可恢复，不跨空档推断持续动作或实体身份。不是任意同义句自由改写。
2. **选项与证据对应**：程序从每个选项拆出最多两个文字片段，优先选区分性的片段；模型不能重写这些主张。此拆分是有界启发式，不保证覆盖选项的全部语义，完整问题与选项仍保留。
3. **具体主张与原文引用校验**：程序为片段查找包含全部归一内容词的候选来源，引用通过代码展开为原文、时间与 caption ID。候选并非语义蕴含证明，模型仍须判断。不存在直接候选时不能输出 observed，只能明确记为推断或未知。直接支持缺词、仅引用其他人物、没有匹配否定却声称矛盾等情形降为未知。未知与矛盾分开，推断与直接观察分开。
4. **严格输出与解析**：两次固定结构解码调用，先匹配主张，再由程序校验，最后读取校验结果及完整原证据选择一个 A–E。选项原文由程序填入，不自由生成解释或置信度，人物 C 不作选项解析。校验不会偷偷改写已选字母；证据不足标志保留。

候选原文预览每个片段最多四条，候选 ID 列表及全部原始证据仍保留。最终选择阶段继续读取完整原证据，防止过严的局部匹配移除答题信息。新增两次读取的输入 token 按每题合计报告，不能与单次 QA 的 token 数混为一谈。
