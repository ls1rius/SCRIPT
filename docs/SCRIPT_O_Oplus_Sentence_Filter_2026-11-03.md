2026-11-05：本页保留逐轮历史；当前 O+ v15 的来源约束实现见末尾。全量错误分析及后续 Q/Q+ 的证据保留合同已整理为 [证据保留与筛选经验记录](Evidence_Retention_Lessons_2026-11-05.md)，后续修改筛选要求时先读该记录。

> 当前实现为 v14，用户最新要求：O/O+ × 带/不带选项，共四组；筛选和O+重组必带问题，选项按同一实验条件开关，最终回答统一带全部选项。抽取共用原句独立抽取结果。此前“不向重组提供问题”的做法已被本次用户指令覆盖；历轮保留作追溯。

用户授权先实现并试验两个版本，尚未训练筛选模型。O 输出结构化信息；O+ 在相同抽取及筛选结果上，额外调用模型重新组织文字。用户进一步明确：无用的剩余片段（例如仅有主语）可以直接丢弃，返回空。因此 O+ 同时允许进一步删减，不能将二者差异全部归因于显示格式。

## 流程

1. 使用 N 已选出的原始来源，每次抽取一句。抽取只接收原句，开放固定全部信息类别，不接受问题、选项或旧N字段请求。每句独立请求，不附带此前句子或模型输出；复查可显式复用冻结抽取并注明。
2. 不做 N 的词面来源匹配、介词/角色值合法性检查或不完整事实强制保留原文。保留 JSON 格式、类型和 ID 完整性检查，以及全部原文、时间及调用档案。
3. 把问题、全部选项、原句和候选信息一起交给筛选模型，每个 ID 返回整数 0/1。动作按主语、动作、对象及各角色拆分，保留动作组关联；属性、状态、关系等按完整记录评分，避免把关系拆成失去含义的孤立词。
4. 全 0 直接删除该句。抽取为空、明确 unavailable 或输出格式不完整时，将原句作为一个候选进行同样的 0/1 筛选；模型运行、超时或基础设施故障仍停止，不伪装成正常抽取失败。
5. 若模型保留动作，同组已抽出的主语与受事对象一并保留；保存原始 model_labels、最终 labels 和 program_overrides。只适用于已存在的字段，不补造缺失值，不改变全0句。O 将最终选中的信息与原始时间区间结构化呈现，不拼入旧N记忆或未筛选原文。
6. O+ 每个有保留信息的句子再调用一次模型。重组输入为问题、该句已选信息，以及按实验条件可选的全部选项；不提供未筛选原文或其他句子。问题/选项只用于判断重要性、组织表达，不作为事实来源；允许无用残片返回空。原本全0的句子跳过重组。
7. 两版分别新生成严格字母答案。没有最终全池规划器、非空约束或自动重试。

当前按句调用，避免整个候选池同时进入模型。实际 tokenizer 在每次调用前检查上下文，不截断。完整新生成时每题调用量约为两倍来源句数，加一次全选项筛选任务说明、O+ 非空句子的重组调用，再加两次回答；逐项成本保存，不能仅凭最终回答输入变短断言总成本下降。

## v6：修正过度筛选并保留明确主语
